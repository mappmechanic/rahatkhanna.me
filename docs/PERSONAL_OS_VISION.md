# Personal OS Vision

Rahat OS is the long-term evolution of the website. It begins as a public executive portfolio, then grows into a personal operating system with public, private, and agentic layers.

## North Star

Create a living mission-control system for Rahat's work, learning, writing, agents, and life direction. The public surface should inspire and build credibility. The private surface should help Rahat operate. The agents surface should coordinate autonomous work with observability and guardrails.

## Three Layers

Public layer:

- Portfolio
- Projects
- Writing
- Speaking
- Vision
- Public dashboards
- Selected progress signals
- Life-story content when provided

Private layer:

- Goals
- Calendar and commitments
- Notes and decisions
- Health and routines
- Learning plans
- Relationship context
- Financial and career planning
- Private reflections

Agents layer:

- Research agents
- Writing agents
- Build agents
- Career agents
- Conference/speaking agents
- Personal knowledge agents
- Evaluation harnesses
- Guardrail policies
- Audit trails
- Publish approvals

## Privacy Boundary

The public site must never automatically expose private data. Any future OS feature that uses personal data needs:

- Authentication.
- Role-based visibility.
- Redaction.
- Audit logs.
- Explicit publish gates.
- Clear public/private labels.
- No secrets in client code.

## Product Phases

Phase 1: Public executive presence

- Design system.
- Landing page.
- Projects, writing, speaking, vision, and OS concept pages.
- Static content and sanitized case studies.

Phase 2: Public live signals

- Manual or static dashboards first.
- Public writing cadence.
- Speaking topics and media kit.
- Selected agent-building progress.
- No private integrations yet.

Phase 3: Private dashboard

- Authentication.
- Private goal and life dashboard.
- Notes and decision log.
- Calendar/task integrations.
- Clear separation from public pages.

Phase 4: Agents mission control

- Agent registry.
- Agent task queues.
- Tool policies.
- Evaluation traces.
- Observability panels.
- Guardrail and human-override workflows.

Phase 5: Publish gate

- Convert private insights and agent outputs into public essays, talks, case studies, and updates.
- Require review before anything goes public.
- Maintain provenance for what generated or informed each public artifact.

## Component Needs

Future reusable components should include:

- Mode switchers for public/private/agents.
- Privacy badges.
- Publish-gate review panels.
- Agent run timeline.
- Evaluation scorecards.
- Trace viewers.
- Mission queue.
- Decision log.
- Goal orbit map.
- Learning radar.
- Speaking pipeline.
- Writing pipeline.
- Life-story timeline.

## Content Implication

The OS idea should not make the public site feel self-indulgent. It should make Rahat feel like a builder of serious systems who also uses those systems on his own life and work.
