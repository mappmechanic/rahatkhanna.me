# rahatkhanna.me

Rahat Khanna's personal website is being redesigned from a traditional portfolio into a public executive presence and the first shell of a future Personal OS.

The public site should communicate, within a few seconds, that Rahat builds the infrastructure that makes AI agents reliable, observable, and enterprise-ready. The long-term direction is broader: a public/private mission-control system for life, work, writing, AI agents, and future operating signals.

## Current Direction

- Position Rahat for senior executive roles at high-growth AI startups and premier labs.
- Build credibility for AI agent conference speaking and thought leadership.
- Publish a long-term vision around AI agents, humanoids, space, and human potential.
- Inspire young technologists through a life and work story that is ambitious, useful, and grounded.
- Evolve the website into Rahat OS: public portfolio, private dashboard, and AI agents mission control.

## App Location

The Next.js app lives in `website/`.

Useful commands:

```bash
cd website
bun install
bun run dev
bun run typecheck
bun run lint
bun run build
```

For local preview after a production build:

```bash
bunx next start -H 127.0.0.1
```
